# 📡 CubeSat Antenna Study

### Selected Antenna — Helical

| Parameter     |      Value      |
| :------------ | :-------------: |
| 📡 Frequency  |   **433 MHz**   |
| 📶 Gain       |    **30 dBi**   |
| ⚖️ Weight     |    **280 g**    |
| 📐 Dimensions | **100 × 66 mm** |

### Why Helical?

* High directivity
* High gain for long-distance communication
* Compact dimensions
* Compatible with CubeSat constraints

**Trade-off:** sensitivity to frequency variations and mechanical vibration, mitigated through structural isolation.
