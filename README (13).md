### 🛰️ OBSAT — CubeSat Meteorológico · Equipe Halley

> **🥇 1° Lugar Nacional (2022 e 2023) · Lançamento Sub-Orbital no CLBI, Natal/RN**

Capitão, programador e desenvolvedor estrutural de um **CubeSat 1U** para detecção antecipada de eventos climáticos severos.

| Subsistema | Especificação |
|---|---|
| 🖥️ Computador de Bordo | PION Labs (C++) |
| 📡 Comunicação RF | Telemetria LoRa 433 MHz helicoidal (30 dBi) |
| 🌍 Posicionamento | GPS + TinyGPS++ (Lat, Long, Alt, Velocidade) |
| 🌡️ Sensoriamento | Temperatura · Pressão · CO₂ · Acelerômetro XYZ · Giroscópio XYZ |
| 💾 Armazenamento | Cartão SD duplo (backup redundante CSV) |
| 🏗️ Estrutura | Alumínio Aeronáutico 7075 · 100×100×100 mm · Etaflon térmico |

// Payload de missão enviado via RF (C++)
#include "PION_System.h"

void loop() {
  DynamicJsonDocument jsonBuffer(512);

  jsonBuffer["pressao"]     = cubeSat.getPressure();

### 🧪 Testes E2E — Meta Pixel Validator

Suite em **Playwright + TypeScript** que simula comportamento humano real para interceptar e validar disparos do Meta Pixel (`PageView`, `InitiateCheckout`, `Purchase`) direto na camada de rede HTTP.

<details>
<summary><b>📋 Ver código</b></summary>

```typescript
// tests/meta-ads-checkout.spec.ts
import { test, expect } from '@playwright/test'

test('jornada completa: criativo → scroll → CTA → checkout', async ({ page }) => {
  const eventos: string[] = []

  page.on('request', (req) => {
    const url = req.url()
    if (url.includes('facebook.com/tr/') && url.includes(META_PIXEL_ID)) {
      const ev = new URLSearchParams(url.split('?')[1] ?? '').get('ev')
      if (ev) eventos.push(ev)
    }
  })

  await page.goto(AD_URL, { waitUntil: 'networkidle' })
  expect(eventos).toContain('PageView')

  await page.evaluate(() =>
    window.scrollBy({ top: window.innerHeight * 0.5, behavior: 'smooth' })
  )
  await page.waitForTimeout(1000)

  const cta = page.locator('button:has-text("Comprar"), [data-cta]').first()
  await cta.click()

  await page.waitForURL(/checkout|cart/, { timeout: 8000 }).catch(() => {})
  expect(eventos).toContain('InitiateCheckout')
})
```

</details>

### 🤖 WhatsApp Bot — Business API + GPT-4o

Backend em **FastAPI + Webhooks** integrado à API oficial da **360Dialog**, com memória de contexto e tempo de resposta < 3 segundos.

<details>
<summary><b>📋 Ver código</b></summary>

```python
from fastapi import FastAPI, Request
from openai import OpenAI

app    = FastAPI()
client = OpenAI(api_key="SUA_API_KEY")
historico: dict[str, list] = {}

@app.post("/webhook")
async def receber_mensagem(req: Request):
    body   = await req.json()
    numero = body["from"]
    texto  = body["text"]["body"]

    if numero not in historico:
        historico[numero] = [{"role": "system", "content": "Diretriz mestre do bot."}]

    historico[numero].append({"role": "user", "content": texto})
    resposta = client.chat.completions.create(
        model="gpt-4o",
        messages=historico[numero]
    )
    reply = resposta.choices[0].message.content
    historico[numero].append({"role": "assistant", "content": reply})
    return {"status": "ok"}
```

</details>
